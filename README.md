# Todo App

A simple and interactive **Todo App** built with **React** to manage daily tasks efficiently. This project helps you learn and practice CRUD operations, React components, and state management.

---

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as complete or incomplete
- Responsive and clean UI

---


## Technologies Used

- **React** – Frontend library for building UI  
- **JavaScript (ES6)** – Application logic  
- **HTML & TailwindCSS** – Markup and styling
- **Vite** – Project bundler and development server
